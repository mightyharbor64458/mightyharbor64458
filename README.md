# Hey, I'm mightyharbor64458

I spend most of my time building tools that make repetitive work disappear. Whether it's scripting deployments or wiring services together, I like systems that stay out of the way once they're set up.

## What I care about

**Python** is my daily driver. I use it for everything from quick data transforms to longer-running services. Clean, readable code beats clever one-liners every time.

**Automation** is where I get the most satisfaction. If a task has to be done more than twice, it probably deserves a script. I've written plenty of small utilities that handle CI checks, environment setup, and scheduled jobs so I can focus on the parts that actually need human judgment.

**Cloud** work has taught me to treat infrastructure as code. Spinning up resources, managing secrets, and keeping costs under control are just as important as the application logic. I prefer straightforward setups over overly complex orchestration unless the scale demands it.

**APIs** are the glue. Designing clear endpoints, handling auth properly, and writing clients that fail gracefully are skills I keep sharpening. Good documentation and predictable error responses save everyone time.

## How I work

I like small, focused repositories. Each project should do one thing well. Tests and type hints help, but only when they pay for themselves. I read other people's code often and try to leave things better than I found them when I contribute.

Outside of code I tinker with Linux setups, experiment with new libraries, and occasionally write notes for future me who will have forgotten why a certain decision was made.

If you're working on something similar or just want to compare notes on tooling, feel free to open an issue or reach out. Always happy to talk shop.
